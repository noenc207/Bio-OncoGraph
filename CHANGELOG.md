# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [2.0.0] - 2026-08-07
### Added
- Complete rewrite for v2.0
- New GNN capabilities for advanced entity recognition
- Enhanced CLI with `train`, `evaluate`, `predict`, `benchmark`, `tune`, `export`, `doctor`, and `version` commands
- Pre-commit hooks for code formatting

### Changed
- Improved overall performance and scalability of knowledge graph construction
