# Security Policy

## Supported Versions

Only the latest major version (2.x) of BioOncoGraph is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within BioOncoGraph, please send an e-mail to security@bio-oncograph.org. All security vulnerabilities will be promptly addressed.
