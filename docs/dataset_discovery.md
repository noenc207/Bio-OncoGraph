# Dataset Discovery

This document lists key datasets for computational pathology.

## TCGA (The Cancer Genome Atlas)
- **Task**: Various (Survival prediction, subtyping, mutation prediction)
- **Size**: ~30,000 WSIs across 33 cancer types.
- **URLs**: [GDC Data Portal](https://portal.gdc.cancer.gov/)

## CPTAC (Clinical Proteomic Tumor Analysis Consortium)
- **Task**: Proteogenomic analysis, multi-omics integration.
- **Size**: Thousands of WSIs linked with mass spectrometry data.
- **URLs**: [CPTAC Data Portal](https://cptac-data-portal.georgetown.edu/)

## CAMELYON (16 & 17)
- **Task**: Metastasis detection in breast cancer lymph nodes.
- **Size**: 400 WSIs (16), ~1000 WSIs (17).
- **URLs**: [CAMELYON16](https://camelyon16.grand-challenge.org/), [CAMELYON17](https://camelyon17.grand-challenge.org/)

## PANDA (Prostate cANcer graDe Assessment)
- **Task**: Prostate cancer grading (Gleason scoring).
- **Size**: 10,616 WSIs.
- **URLs**: [PANDA Challenge on Kaggle](https://www.kaggle.com/c/prostate-cancer-grade-assessment)
