# BioOncoGraph v2.0

BioOncoGraph is a comprehensive open-source framework for building and analyzing biomedical knowledge graphs with a specific focus on oncology.

## Features
- Scalable Knowledge Graph Construction
- Advanced Graph Neural Network (GNN) capabilities
- End-to-end pipelines for training, evaluation, and prediction
- Pre-trained models for oncological named entity recognition and relation extraction

## Quick Start
```bash
pip install bio-oncograph
bio-oncograph train --config configs/train.yaml
bio-oncograph evaluate --model-path models/best_model
```
